# Balance Game (MuJoCo + C++)

막대를 똑바로 세우는 3D 균형 게임의 시작 골격입니다.

## 폴더 구조
```
BalanceGame/
├─ CMakeLists.txt
├─ README.md
├─ assets/
│  └─ balance.xml   (모델 템플릿: 난이도 값이 실행 시 채워짐)
└─ src/
   ├─ levels.h      (난이도 표)
   └─ main.cpp
```

## 사전 준비 (Windows)
- Visual Studio 2022 + "C++를 사용한 데스크톱 개발" 워크로드
- CMake (VS에 포함된 버전 사용 가능)
- 선택: "C++ Clang 도구" (MuJoCo 문서에 따르면 Windows에서는 Clang이 성능이 더 좋았다고 함)

## 빌드
MuJoCo는 `CMakeLists.txt`에서 `3.9.0` 태그로 고정되어 있으며, 첫 configure 시 자동으로 내려받습니다.

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Clang을 쓰려면 다음과 같이 configure 합니다.
```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -T ClangCL
```

## 실행
```
build\Release\balance_game.exe
```
빌드 시 `assets` 폴더가 실행 파일 옆으로 복사됩니다.

`build\Release\balance_game.exe 8` 처럼 숫자를 주면 그 레벨부터 시작합니다.

## 난이도 (12단계)
| Lv | 이름 | L [m] | g [m/s²] | 1/λ [s] | 회복 가능 각도 | 입력 지연 | 외란 | 비고 |
|---|---|---|---|---|---|---|---|---|
| 1 | 기초 | 1.20 | 5.00 | 0.400 | 전 각도 | 0 ms | 없음 | 자동 보조 60 % |
| 2 | 초급 | 1.00 | 9.81 | 0.261 | 전 각도 | 0 ms | 없음 | 자동 보조 30 % |
| 3 | 중급 | 0.80 | 9.81 | 0.233 | 전 각도 | 0 ms | 0.3 rad/s | |
| 4 | 상급 | 0.65 | 9.81 | 0.210 | 전 각도 | 20 ms | 0.5 rad/s | |
| 5 | 고급 | 0.50 | 9.81 | 0.184 | 58° | 30 ms | 0.7 rad/s | 회복 불가 영역 등장 |
| 6 | 심화 | 0.45 | 11.0 | 0.165 | 49° | 40 ms | 0.9 rad/s | |
| 7 | 최상위 | 0.40 | 13.0 | 0.143 | 41° | 50 ms | 1.0 rad/s | |
| 8 | 전문가 | 0.35 | 15.0 | 0.125 | 33° | 45 ms | 1.2 rad/s | |
| 9 | 마스터 | 0.30 | 18.0 | 0.105 | 30° | 40 ms | 1.3 rad/s | |
| 10 | 그랜드마스터 | 0.25 | 24.79 | 0.082 | 27° | 35 ms | 1.4 rad/s | 목성 중력 |
| 11 | 전설 | 0.20 | 30.0 | 0.067 | 24° | 30 ms | 1.5 rad/s | |
| 12 | 신 | 0.15 | 40.0 | 0.050 | 21° | 22 ms | 1.5 rad/s | 사람 반응 시간(~0.2 s)의 1/4 |

- **λ = sqrt(3g / 2L)**: 막대가 짧고 중력이 클수록 빨리 넘어진다 (1/λ = 넘어지는 시간 상수).
- **회복 가능 각도 θmax = asin(2τmax / mgL)**: 이 각도(화면의 빨간 선)를 넘으면 무엇을 해도 넘어진다.
- **λ · 지연**: 상위 레벨일수록 커진다. 신 레벨(≈0.44)은 내장 PD 자동 제어가 겨우 버티는 한계 근처.
- 20초 버티면 **클리어**, 레벨별 최고 기록은 `progress.txt`에 저장됩니다.
- 값 조정은 `src/levels.h` 한 곳에서 하면 됩니다.

## 조작
| 키 | 동작 |
|---|---|
| ← / → (A / D) | 토크 |
| Shift | 미세 조작 (토크 30 %) |
| ↑ / ↓, 1–9, 0, -, = | 레벨 변경 (0 = Lv10, - = Lv11, = = Lv12) |
| R | 재시작 |
| P | 자동 PD 제어 켜기/끄기 (사람 vs 기계) |
| Space | 일시정지 |
| Esc | 종료 |

HUD는 MuJoCo 폰트가 ASCII만 지원해서 영어로 표시되고, 한국어 레벨 이름은 창 제목에 나옵니다.

## 자체 검증
```
build\Release\balance_game.exe --selftest
```
창 없이 각 레벨을 자동 PD 제어로 돌려 클리어 여부를 확인하고,
제어 없이 넘어지는 시간을 해석해 `acosh(θf/θ0)/λ` 와 비교합니다 (오차 약 1 %).
