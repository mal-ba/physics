# 기획서: Balance Lab — "게임이 곧 물리 실험"

## 한 줄 컨셉
막대 세우기 게임을 하면서 **플레이어 자신이 실험 대상**이 된다.
게임 기록으로 *내 반응 시간*을 역산하고, 시뮬레이션 결과를 **해석해와 비교**한다.

## 참고(MuJoCo)와 다른 점 — 새로운 아이디어
| MuJoCo 예제 | 이 프로젝트 |
|---|---|
| 컨트롤러가 막대를 세움 | **사람이** 세우고, 컨트롤러(PD / LQR)는 비교 대상 |
| 시뮬레이션만 보여줌 | 해석해(선형화 운동방정식)와 **정량 비교** |
| 고정된 물리 상수 | 중력·길이·질량을 바꿔 가며 **"사람이 세울 수 있는 한계"** 측정 |

## 핵심 물리
막대(길이 L, 질량 m, 끝점 회전)의 운동방정식:

    I θ'' = m g (L/2) sin θ + τ,   I = m L² / 3

작은 각도 근사(sin θ ≈ θ), τ = 0일 때:

    θ(t) = θ₀ cosh(λt),   λ = sqrt(3g / 2L)

- **1/λ = 넘어지는 시간 상수.** L = 0.5 m, g = 9.81일 때 1/λ ≈ 0.18 s → 사람 반응 시간(약 0.2 s)과 비슷.
  → 짧은 막대일수록, 중력이 클수록 세우기 어렵다는 것을 **수식으로 예측하고 게임으로 확인**.
- **토크 한계와 회복 가능 각도:** |τ| ≤ τmax 이면 θ_max = asin(2 τmax / (m g L)).
  이 각도를 넘으면 무슨 짓을 해도 넘어진다 → HUD에 "회복 불가 영역"으로 표시.
- **에너지:** E = ½ I ω² + m g (L/2) cos θ, 플레이어 토크가 한 일 W = ∫ τ ω dt → 에너지 보존 확인.

## 모드
1. **Free Fall 실험** — 제어 없이 쓰러뜨려 θ(t)를 기록하고 cosh(λt)와 겹쳐 그림 (시뮬레이터 검증).
2. **Play** — ←/→ 로 토크. 생존 시간 = 점수.
3. **Limit Test (핵심 아이디어)** — 버틸 때마다 막대가 짧아지거나 중력이 커진다.
   실패한 지점의 λ_c 로 *내 유효 반응 시간* ≈ 1/λ_c 를 추정.
4. **Human vs Machine** — 같은 외란에 사람 / PD / LQR 성능 비교
   (LQR은 MuJoCo `mjd_transitionFD`로 선형화해서 구함).

## HUD / 시각화
- 위상 공간 그래프 (θ, ω) + 회복 불가 경계선 (`mjr_figure`)
- 에너지 그래프, 현재 g · L · λ 값
- 실험 결과 CSV 저장 → 보고서용 그래프

## 3주 일정 (1인)
| 주 | 목표 | 완료 기준 |
|---|---|---|
| 1 | 키보드 토크 입력, 넘어짐 판정, 점수, 파라미터(g, L, m) 변경 구조, CSV 로깅 | Play 모드 동작 |
| 2 | Free Fall 실험 + 해석해 비교, 위상 공간 / 에너지 HUD, Limit Test 모드 | 시뮬 vs 해석 오차 그래프 |
| 3 | PD / LQR 비교 모드, 외란, 정리 · 보고서 · 시연 영상 | 발표 가능 |
